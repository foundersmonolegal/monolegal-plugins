# Qué cuenta como actuación

Una **actuación** es una interacción con carácter jurídico entre el abogado, el cliente, el juzgado o la otra parte. Es lo que el cliente verá en la app.

## Sí cuenta

| Ejemplo | Autor |
|---|---|
| El juzgado admite la demanda, cita a vista, dicta sentencia o requiere algo | Juzgado |
| El abogado presenta la demanda, la contestación, un recurso o propone prueba | Abogado |
| El abogado acude a una vista o a una conciliación | Abogado |
| El cliente entrega un documento necesario para el caso (poder, contrato, nóminas) | Cliente |
| El cliente firma un poder o se ratifica en persona | Cliente |
| La otra parte contesta, recurre, se opone o paga | Contraparte |
| La Administración registra, requiere, resuelve o notifica (Oficina de Extranjería, UGE-CE, un ayuntamiento) | Administracion |

## No cuenta

- Saludos, agradecimientos, recordatorios genéricos ("¿cómo va lo mío?").
- Gestiones internas del despacho: honorarios, facturas, provisiones de fondos, agenda.
- Resoluciones de mero trámite sin efecto para el cliente (únase, se tiene por personado, cambio de procurador).
- Opiniones o valoraciones del abogado sobre el cliente o el caso.

## Cómo describirla para el cliente

- Lenguaje llano, una o dos frases, sin artículos de ley: "El juzgado ha admitido tu demanda y la empresa tiene diez días para contestar".
- En segunda persona y sin nombres: "Has enviado las facturas", no "[CLIENTE] envió las facturas". Así lo que llega a la app no lleva datos personales.
- Nunca datos personales de terceros (direcciones, DNI, datos de salud de la otra parte).
- La cita literal y el documento de origen van aparte, solo para el abogado.
